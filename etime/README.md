# etime (Blender)

## Included

- `etimeNew27.blend`
- Earth / moon: `8k_earth_daymap.jpg`, `8k_earth_nightmap.jpg`, `_moon0.jpg`
- Sun: `sun.jpg`, `sunmap.jpg`
- Metals: `gold.jpg`, `silver.jpg`
- UI / overlays: `onePg2.png`, `onePg3.png`, `onePg4.png`
